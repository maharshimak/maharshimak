# 🧬 Clinical Document Intelligence

A **synthetic-data-only** document intelligence project for extracting and validating structured facts from clinical-style study text.

This repository is intentionally independent of any former employer's code, data or architecture.

## Implemented

- rule-based extraction from synthetic study text
- normalized study fields
- validation checks
- confidence annotations
- test fixtures with invented data

## Example fields

- study identifier
- phase
- intervention
- participant count
- primary endpoint

The next step is replacing rule-based extraction with a model-assisted pipeline plus human-verifiable evidence spans.
