# Maharshi Patel — Engineering Portfolio

This directory contains six focused AI engineering projects designed to demonstrate different parts of a production AI stack.

| Project | Focus |
|---|---|
| [Mak'ma AI OS](./makma-ai-os/) | Agent orchestration, memory, tools, personal AI architecture |
| [Agentic RAG Engine](./agentic-rag-engine/) | Hybrid retrieval, fusion, citations, agentic RAG |
| [Multimodal AI Studio](./multimodal-ai-studio/) | Prompt-driven media-edit planning and multimodal pipelines |
| [Knowledge Twin](./knowledge-twin/) | Knowledge graphs, semantic retrieval, entity relationships |
| [Clinical Document Intelligence](./clinical-document-intelligence/) | Synthetic clinical-document extraction and validation |
| [MLOps Production Pipeline](./mlops-production-pipeline/) | Training lifecycle, model registry concepts, monitoring and drift |

## Engineering standards

Each project is built with the same principles:

- clear architecture and boundaries;
- testable core logic;
- no private employer code or datasets;
- no committed credentials;
- container-ready structure;
- automated CI;
- explicit roadmap and limitations;
- documentation that explains both the **why** and the **how**.

These are public portfolio implementations built from scratch.
